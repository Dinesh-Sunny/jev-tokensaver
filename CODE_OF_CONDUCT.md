# Code of Conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct.

In short: be welcoming, be respectful, assume good intent, and focus on what is best for the community. Harassment, personal attacks, discriminatory language and publishing others' private information are not tolerated.

## Reporting

To report unacceptable behaviour, contact the maintainer privately through [GitHub](https://github.com/Dinesh-Sunny), or use the "Report content" option on the comment or issue. All reports are reviewed and handled confidentially. The maintainer may remove, edit or reject contributions and may ban contributors who breach this code, following the enforcement guidelines in the Contributor Covenant.
